# 学术心流站 · ScholarFlow

本地优先的科研工作台：文献检索与精读、翻译、综述分析、数据图表、论文写作、组会幻灯片、学习中心、知识库。
大模型在本机运行，论文与笔记不出硬盘。

## 安装

1. 下载对应安装包；
2. 双击安装，全程无需管理员权限；
3. 安装完成后从开始菜单启动「学术心流站」；
4. 首次启动约 10–20 秒（正在启动本地推理引擎）。

安装包已内置运行环境，**无需安装 Python 或其它依赖**。

## 运行环境

- Windows 10 / 11（64 位）
- 内存 16GB 及以上（推荐 32GB）
- 显卡可选；NVIDIA 8GB 显存以上可加速本地模型（x64 版）
- 磁盘：安装约 1.5GB，每个本地模型额外 4–7GB

## 使用

安装后请先阅读《学术心流站-v0.2.0-使用说明书.docx》，内含登录、三个工作台说明、本地模型安装、隐私等级、常见问题与卸载方式。
